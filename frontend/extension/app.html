Setting up Filewise for the first time?+

Connect your Google Drive

This extension needs a Google project configured by its maintainer before sign-in and the Drive file picker can work.

  1. Enable the Google Drive API and Google Picker API in your Google Cloud project.
  2. Configure the OAuth consent screen and create a Chrome extension OAuth client. Its extension ID must match the installed extension.
  3. Add that OAuth client ID to manifest.json and the public Google Picker API key and project settings to the extension configuration.
  4. Reload the extension, then select Connect Drive. Development projects may need your Google account added as a test user.

The API key is public extension configuration. Never place a Google client secret or service account key in the extension.
